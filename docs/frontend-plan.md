# 本地 Agent 控制台实施计划

目标：复用现有 Agent，完成任务提交、实时进度、协作停止、结果和历史查看。

## 实施顺序

1. 提取 `bootstrap.py`，统一 CLI 与 Web 的配置校验、模型及工具装配和资源生命周期。
2. 增加 `service/`：每个任务独立 Windows spawn 进程；SQLite 保存任务与已脱敏事件；同一时刻只运行一个任务。任务终态以工作进程返回值为准，文件日志故障独立隔离。
3. 增加 `api/`：FastAPI 提交/查询/停止任务，SSE 按事件游标续传；仅在回环地址启动，检查 Host 与 Origin。模型密钥不通过浏览器传入或返回。
4. 增加 `frontend/`：React、TypeScript、Vite、Ant Design；由 OpenAPI 生成接口类型；任务编辑、运行设置、历史、执行时间线、错误详情与最终回答。
5. 验证：原有离线测试、新增任务生命周期/API/事件恢复测试、前端类型检查和构建、真实浏览器端到端验证。使用测试模型，不调用付费模型或执行真实桌面动作。
6. 补充运行说明和 AI 维护约定，交付可在 Conda agent 环境启动的本地应用。

## 第一版边界

- 保留 `python main.py`；新增 `python web.py`。
- SQLite 数据和 JSONL 日志保存在忽略的 `.agent-data/` 与 `.agent-logs/`。
- 正常停止使用取消信号，在模型/工具边界检查；等待中的网络或 Shell 调用不会立刻返回。桌面 F8 急停继续有效。
- 服务重启时，将遗留活动任务标为 interrupted，避免显示虚假的运行状态；不自动重做可能产生副作用的任务。
- 浏览器断开不影响运行；SSE 重新连接从已保存游标继续。
- 暂缓上下文压缩、桌面安装包、多用户服务和并行桌面任务。

## 验收

- 提交后立即返回任务 ID，界面保持响应。
- 进度、成功、失败、取消与中断均准确显示。
- 刷新可恢复历史、结果与事件，停止操作幂等。
- 日志故障不关闭界面事件；界面断开不关闭文件日志。
- API 与页面不返回模型密钥或截图编码；接口由同一份 OpenAPI 定义维护。

## 实施结果

- 已完成共享 bootstrap、工作进程、SQLite 任务/事件、单任务互斥、协作取消、启动实例锁和异常退出恢复。
- 已完成 FastAPI、OpenAPI 生成、HTTP 查询与提交、SSE 游标续传及本机来源校验。
- 已完成前端任务编辑、模型与桌面设置、历史恢复、时间线和详情、最终回答、复制为新任务及停止状态。
- 已完成原有功能回归、真实 spawn/HTTP 集成验证、前端组件测试、类型检查与生产构建。
- 最终验证：146 项 Python 测试、7 项前端测试通过；`pip check` 无依赖冲突。
- 浏览器工具无法验证管理员安全策略，因此真实浏览器布局及交互验收未完成；未绕过安全检查。
- 真实模型调用和真实桌面动作未在本次验证中执行；测试服务使用离线模型和内存工具。
