# 复杂任务的验收证据

验收条件应对应用户要求，不能只检查“工具调用没有报错”。

| 任务 | 合适的检查 | 不足以证明完成的现象 |
| --- | --- | --- |
| 批量整理数据 | 输入输出数量、主键去重、必填字段、合计一致 | 只检查输出文件存在 |
| 修改程序 | 对应行为的测试、检查真实退出码和超时状态 | 只检查源码包含某段文本 |
| 网页操作 | 重新读取实际结果、记录 ID 或状态变化 | 只检查点击函数返回成功 |
| 生成文档 | 内容覆盖、实际可打开、必要时渲染检查 | 只检查文件大小大于零 |

当前 task_verify 的确定性检查类型包括 file_contains、file_equals、file_sha256、command_succeeded。
使用命令验收时，应引用实际运行的命令调用 ID，并检查命令确实覆盖所需行为。
没有足够证据时记录 uncertain，不能把推测写成已验证结果。
