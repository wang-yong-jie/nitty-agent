name: complex-task
description: 处理需要多个阶段、保存进度和独立验收的复杂任务，例如批量整理资料、修改并验证项目、生成可核对的任务产物。简单问答和一次即可完成的操作不需要此 Skill。
compatibility: 需要启用长任务模式；具体操作还需要对应的文件、Shell、桌面或浏览器工具。

先明确用户目标、输入范围、最终产物和验收证据。已能从当前上下文确认的信息不重复询问。

使用 task_plan 建立带稳定 ID 的里程碑。按可观察的结果划分步骤，例如“生成去重明细并核对条数”，
避免把“思考”“调用工具”当成业务里程碑。不要在没有读取当前状态时重复覆盖原计划。

执行每个阶段时，通过现有工具获取真实输入。用 task_progress 保存来源明确的事实、决定、当前步骤，
以及产物路径。大量明细保存到文件等已有持久化能力中，任务状态只保留索引和关键数量。

阶段完成后调用 task_verify，依据真实文件、命令结果或环境证据验收。只有验收通过才标为完成。
验收设计见 references/acceptance.md，需要设计检查条件时通过 read_skill_resource 加载。

操作报错时，先区分参数错误、环境问题与可能已经产生影响的操作。对结果不明的提交、写入和发送，
先查询或核对已有产物，不直接重试。任务恢复后重新获取当前环境，核实未决操作，不能依赖历史截图。

最终逐项核对用户要求，报告产物位置、已验证结果以及未完成或无法确认的部分。
本 Skill 不提供浏览器工具，也不会自行安装依赖；需要的能力不存在时明确说明缺少什么。
